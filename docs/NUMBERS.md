# Numerical results and their sources

This ledger follows the article tables, then gives all 252 Supplemental records. Each number has its formula, operation, measurement or record source, printed address and named theorem. The units of a scaled catalogue row are stated explicitly. The main tables use the article's physical units. All values in the calculated columns below are read from `outputs/article_results.json`, written by `programs/article_results.py`.

The full equation-by-equation route is [ARTICLE_CONCORDANCE.md](ARTICLE_CONCORDANCE.md). [INPUTS.md](INPUTS.md) gives the measured unit and conventional inputs. [PROOFS.md](PROOFS.md) explains what each Lean statement proves. A conventional calculation record is an input to the reporting calculation; its generating prescription is stated where it is available.
